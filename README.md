# PilotSpace — тренажёр ЧЛЭ

Сайт проекта: [pilotspace.ru](https://pilotspace.ru/)

Порядок развития и решения по серверной части: [ARCHITECTURE.md](ARCHITECTURE.md).

## Страницы разделов и иконки

Каталог `sections/index.html` и 22 страницы тем генерируются из банка командой `node build_sections.cjs`. Содержимое доступно без JavaScript: названия, количество вопросов, подразделы и пять примеров без картинок. Ссылка `index.html?section=3.7` выбирает раздел, не запускает новую попытку и не заменяет сохранение. Генератор также обновляет sitemap. Перед выпуском выполнять `node build_sections.cjs`, затем `node build_offline.cjs`; для проверки — обе команды с `--check`. Добавление страниц само по себе не подтверждает индексацию: после публикации проверить Search Console и Яндекс Вебмастер.

Иконки установленного приложения экспортируются из `favicon.svg` командой `python build_icons.py` (PyMuPDF). Новые `*-v2.png` имеют сплошной фон; Android-версия держит знак внутри безопасного круга радиусом 40% ширины. Новые адреса изображений указаны в прежнем `site.webmanifest`, идентификатор приложения не меняется. Chrome может обновить значок установленного приложения не сразу.

Название и иконки для добавления на экран телефона заданы в `site.webmanifest`; для iOS добавлена `apple-touch-icon`. Офлайн-режим включается явно кнопкой скачивания. Векторный исходник знака — `favicon.svg`, PNG-версии находятся в `icons/`.

Для офлайн-режима откройте сайт по HTTPS либо локально через `http://localhost`. Обычный запуск `index.html` как файла остаётся возможным, но service worker в `file://` не работает.

База содержит 2 854 вопроса из приложенного PDF, все допущены к тренировкам. Исходные расхождения и точечные исправления перечислены в [SOURCE_REVIEW.md](SOURCE_REVIEW.md).

- Выберите раздел, подраздел/систему самолёта и диапазон.
- Для короткого подхода выберите 10, 20 или 50 вопросов: приложение случайно отберёт их из выбранного раздела и подраздела без повторов внутри тренировки. По умолчанию выбрано 20. Если вопросов меньше, будут включены все. «Свой диапазон» открывает прежний выбор диапазонов и переключатель порядка. Сохранённая тренировка продолжается с той же подборкой.
- В обычном вопросе нажмите один вариант. В вопросе с несколькими ответами выберите все подходящие варианты и нажмите «Проверить ответ». Балл даётся только за полный правильный набор.
- У каждого вопроса есть ссылки на его страницу PDF и таблицу ответов. Исходный PDF лежит рядом с `index.html`; он не входит в офлайн-пакет.
- Папку `images` нужно сохранять рядом с `index.html`: в ней находятся рисунки и фрагменты формул.

## История обновлений

`updates.html` — отдельный статический журнал: не требует сервера и не загружает базу вопросов. Использует общие стили и `theme.js`. Главная ссылается на него из вступления и подвала. Версия 1.0.0 начинает нумерацию; более ранние записи основаны на датах Git.

При выпуске добавьте в начало списка `release-timeline` запись с уникальным якорем, версией, датой в `<time datetime="YYYY-MM-DD">` и кратким описанием проверенных изменений. Обновите номер в двух ссылках `index.html`; скорректируйте блок планов. Публикуйте запись вместе с изменениями: локальная подготовка ещё не означает выпуск на сайте. Версия интерфейса независима от версии банка вопросов и ключей сохранения.

Используем формат MAJOR.MINOR.PATCH: крупное несовместимое изменение, новая возможность, исправление. Версия 1.1.0 добавляет офлайн-режим. Не включайте обещания сроков и ещё не реализованные функции в список готового.

## Офлайн и выпуск обновлений

Кнопка «Скачать для офлайн» регистрирует `sw.js` и скачивает весь пакет: около 8,9 МиБ, 76 файлов, включая базу и все 60 иллюстраций. Полный PDF не скачивается. Первый запуск требует сети; «Готово» появляется после проверки наличия всех файлов. После первого скачивания нужно открыть сохранённую версию кнопкой на странице. Перед поездкой рекомендуется проверить открытие сайта без интернета в том же браузере и по тому же адресу.

`build_offline.cjs` генерирует `sw.js` из `sw-template.js` и `offline-info.json`. SHA-256 каждого ресурса предотвращает установку смеси разных выпусков; незавершённая установка не затрагивает старый кэш. После включения режима браузер может загружать новую версию при следующем посещении, либо пользователь запускает проверку кнопкой. `skipWaiting` и `clients.claim` не используются: новая версия ждёт закрытия всех вкладок, поэтому открытая тренировка не переключается на другую базу. Закрытие вкладок не уничтожает localStorage; изменение версии банка по-прежнему делает старую тренировку несовместимой.

После изменения любого файла интерфейса, банка или изображений обязательно выполнить:

```text
node build_offline.cjs
node --test test_app.cjs test_offline.cjs
node build_offline.cjs --check
```

Публиковать сгенерированные файлы вместе с ресурсами одним выпуском. Проверка `--check` ловит забытое обновление пакета. Service worker работает и в корне домена, и в подпапке GitHub Pages. Кэшируются только перечисленные собственные файлы; письма, внешние сайты и полный PDF требуют сети. При недоступном PDF отображается понятная страница возврата в тренажёр. Браузер может удалить кэш и прогресс при очистке данных или нехватке места; офлайн-копия не является резервной копией прогресса. Проверка ёмкости предварительная, фактический отказ записи тоже обрабатывается.

## Прогресс и ошибки

Прогресс сохраняется автоматически через `localStorage`: порядок вопросов, счёт, проверенный ответ и незавершённый выбор нескольких вариантов. На главной странице кнопка «Продолжить тренировку» возвращает к сохранённому вопросу. Хранится одна незавершённая тренировка; запуск новой заменяет её.

Ошибочные вопросы попадают в список «Работа над ошибками». Их можно просмотреть и повторить отдельно, независимо от фильтров. Правильный ответ при следующей попытке убирает вопрос из списка. Исключённые вопросы PDF в него не попадают.

После завершения показан разбор текущей попытки: по умолчанию только ошибочные вопросы, переключатель открывает все. Раскрывающиеся карточки показывают результат, правильные варианты, примечания и ссылку на исходный вопрос. Разбор доступен на экране результата до новой тренировки или перезагрузки; отдельный архив завершённых попыток пока не сохраняется. Общий список ошибок продолжает храниться автоматически. Логотип на главной возвращает к настройкам без перезагрузки и потери незавершённой попытки.

Сохранение действует только в этом браузере для этого адреса сайта, без автоматической синхронизации устройств. Очистка данных сайта удаляет прогресс. При запрете хранилища приложение показывает сообщение и позволяет тренироваться без сохранения. При изменении базы старый прогресс не используется. Для стабильного сохранения открывайте сайт по одному и тому же HTTP(S)-адресу: поведение `localStorage` при открытии через `file://` зависит от браузера.

## Пересборка базы

Из папки `quiz_app`, с установленным Python:

```text
python -m pip install -r requirements.txt
python extract_questions.py
python -m unittest test_import.py
node --test test_app.cjs
```

В существующем Windows-окружении можно заменить `python` на `venv\Scripts\python.exe`.

Импорт заново читает все страницы PDF, отделяет заголовки по структуре и колонтитулы по координатам, сверяет ключи и выделения, извлекает рисунки. Структурные ошибки блокируют перезапись базы. Ручные исправления опечаток привязаны к SHA-256 исходника; при замене PDF требуется новая проверка.

`questions.json` и `questions.js` генерируются вместе. Правильные ответы хранятся массивом `correct_answers`. У записей `status: needs_review` этот массив пуст; исходные ключи и выделения сохранены в `table_answers` и `highlighted_answers`. `audit_report.json` содержит сведения о полноте и спорных вопросах.

## Перенос прогресса и сообщения об ошибках

В настройках раскройте «Сохранить или перенести прогресс». JSON-файл содержит одну незавершённую тренировку и список ошибок. При загрузке приложение проверяет формат, версию банка и целостность данных, показывает состав сохранения и просит подтвердить замену. Данные не объединяются. Несовместимый или повреждённый файл не меняет текущий прогресс; отказ браузера в записи тоже не заменяет активное сохранение. Максимальный размер файла — 2 МБ. Файл можно перенести между устройствами и доменами при одинаковой базе.

Ссылка у вопроса открывает почтовый клиент с uid, разделом, страницами PDF и текстом вопроса (до 600 символов). Пользователь дописывает проблему и сам отправляет письмо. Серверной отправки нет.

Публичные записи пишутся от первого лица Дмитрия Морозова: «добавил», «исправил», «работаю». Уместен короткий добровольный призыв поддержать работу над конкретным обновлением; не обещаем сроки за донат.

Повторная проверка от 27.09.2026: все 14 спорных вопросов возвращены в тренировки. Для вопроса 3.5.1:22 восстановлен угол γ и исправлен ошибочный ключ PDF на B; исходный ключ сохранён для аудита. Пользовательский режим без оценки удалён. Подробности: [QUESTION_REVIEW.md](QUESTION_REVIEW.md); воспроизводимые решения: `answer_resolutions.json`. Обновление базы меняет её ревизию: прежние сохранения не применяются автоматически.

## Карточки ссылок

Главная, журнал и страницы разделов содержат Open Graph и Twitter Card с общей обложкой `social/pilotspace-share-v1.png` (1200 × 630). Изображение доступно по абсолютному HTTPS-адресу без JavaScript. Для перерисовки: `python build_social.py` (PyMuPDF и шрифты Segoe UI в Windows). После изменения шаблона страниц: `node build_sections.cjs`, затем `node build_offline.cjs`. При замене обложки используйте новое имя файла и обновите метаданные: социальные сети кэшируют изображения.

Установка: `install.js` показывает кнопку на главной, использует системный диалог по нажатию и инструкции, если диалог недоступен. Подтверждение готовности офлайн-пакета открывает предложение; «Позже» скрывает его на 7 дней. В отдельном окне приложения блок скрыт. Проверки: `node --test test_install.cjs test_app.cjs test_offline.cjs`.

История тренировок: последние 20 завершённых попыток (дата, uid вопросов и результат каждого ответа) сохраняются в том же локальном сохранении и файле переноса. Старые файлы без истории поддерживаются; импорт заменяет историю после подтверждения. Разбор использует текущую совместимую базу, при изменении ревизии история сбрасывается. Просмотр истории не меняет незавершённую тренировку и список ошибок.

Поиск разделов: поле «Найти раздел» ищет по названию темы и модели самолёта, принимает A320/А320 и русские названия Airbus/Boeing. Выбор совпадения обновляет раздел и системы, не запускает тренировку и не заменяет сохранённую попытку. Поиск выполняется локально и доступен офлайн.

Избранное: кнопка у вопроса отмечает его без изменения ответа и счёта. Подборка доступна на главной и запускается целиком независимо от фильтров и выбранного объёма короткой тренировки. Удаление отметки во время попытки не удаляет вопрос из уже запущенной тренировки. Избранное сохраняется в локальном прогрессе и переносится в JSON; старые файлы без поля favorites поддерживаются.

Размер текста: три варианта в настройках и у вопроса синхронизируются и сохраняются отдельно в localStorage (pilotspace-text-size). Настройка меняет только текст вопроса, вариантов, примера и разбора. Не входит в файл переноса прогресса; при запрете хранилища действует до закрытия страницы.

Помощь пользователям: help.html, доступна без JavaScript и входит в офлайн-пакет. Подключение Google Search Console и Яндекс Вебмастера описано в SEO_SETUP.md; наличие карты сайта не означает, что кабинеты уже подключены или все страницы проиндексированы.

## О проекте и изучение по темам

`about.html` описывает аудиторию, состав базы MY FREIGHTER и специфику правовых вопросов Узбекистана. `learn.html` и 22 страницы `sections/*-study.html` дают чтение всех 2854 вопросов с ответами, изображениями и source_note без оценки и изменения прогресса. Это повторение по тестовой базе, а не курс с самостоятельными техническими объяснениями. Все страницы генерируются через `build_sections.cjs`, входят в sitemap (50 URL) и офлайн-пакет.

Полная проверка: `node --test test_app.cjs test_install.cjs test_offline.cjs test_content.cjs`. Проверка контента сравнивает каждый ответ и примечание с действующим банком.
