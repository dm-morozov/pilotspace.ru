# Тренажёр ЧЛЭ

Откройте `index.html` в браузере. Установка Python и запуск сервера для тренировки не нужны. После обновления базы перезагрузите страницу (Ctrl+F5).

База содержит 2 854 вопроса из приложенного PDF: 2 840 для тренировки и 14 для просмотра без оценки. Причины неоднозначности и страницы источника перечислены в [SOURCE_REVIEW.md](SOURCE_REVIEW.md).

- Выберите раздел, подраздел/систему самолёта и диапазон.
- Для короткого подхода выберите 10, 20 или 50 вопросов: приложение случайно отберёт их из выбранного раздела и подраздела без повторов внутри тренировки. По умолчанию выбрано 20. Если вопросов меньше, будут включены все. «Свой диапазон» открывает прежний выбор диапазонов и переключатель порядка. Сохранённая тренировка продолжается с той же подборкой.
- В обычном вопросе нажмите один вариант. В вопросе с несколькими ответами выберите все подходящие варианты и нажмите «Проверить ответ». Балл даётся только за полный правильный набор.
- Для просмотра спорных вопросов переключите режим. Они не участвуют в тренировке и подсчёте баллов.
- У каждого вопроса есть ссылки на его страницу PDF и таблицу ответов. Для работы ссылок исходный PDF должен лежать на уровень выше папки `quiz_app`, как в этом проекте.
- Папку `images` нужно сохранять рядом с `index.html`: в ней находятся рисунки и фрагменты формул.

## Прогресс и ошибки

Прогресс сохраняется автоматически через `localStorage`: порядок вопросов, счёт, проверенный ответ и незавершённый выбор нескольких вариантов. На главной странице кнопка «Продолжить тренировку» возвращает к сохранённому вопросу. Хранится одна незавершённая тренировка; запуск новой заменяет её.

Ошибочные вопросы попадают в список «Работа над ошибками». Их можно просмотреть и повторить отдельно, независимо от фильтров. Правильный ответ при следующей попытке убирает вопрос из списка. Спорные вопросы PDF в него не попадают.

Сохранение действует только в этом браузере для этого адреса сайта, без синхронизации устройств. Очистка данных сайта удаляет прогресс. При запрете хранилища приложение показывает сообщение и позволяет тренироваться без сохранения. При изменении базы старый прогресс не используется. Для стабильного сохранения открывайте сайт по одному и тому же HTTP(S)-адресу: поведение `localStorage` при открытии через `file://` зависит от браузера.

## Пересборка базы

Из папки `quiz_app`, с установленным Python:

```text
python -m pip install -r requirements.txt
python extract_questions.py
python -m unittest test_import.py
node --test test_app.cjs
```

В существующем Windows-окружении можно заменить `python` на `venv\Scripts\python.exe`.

Импорт заново читает все страницы PDF, отделяет заголовки по структуре и колонтитулы по координатам, сверяет ключи и выделения, извлекает рисунки. Структурные ошибки блокируют перезапись базы. Ручные исправления опечаток привязаны к SHA-256 исходника; при замене PDF требуется новая проверка.

`questions.json` и `questions.js` генерируются вместе. Правильные ответы хранятся массивом `correct_answers`. У записей `status: needs_review` этот массив пуст; исходные ключи и выделения сохранены в `table_answers` и `highlighted_answers`. `audit_report.json` содержит сведения о полноте и спорных вопросах.
