          PilotSpace готов к дороге

          Добавьте приложение на главный экран — тренировки будут под рукой.

          Установка добавит иконку приложения. Для занятий без сети отдельно скачайте офлайн-пакет выше.

          Как пользоваться в дороге

          Скачайте пакет и дождитесь сообщения «Готово». Перед поездкой проверьте: отключите интернет и откройте сайт заново.

          Открывайте тот же адрес в том же браузере. Можно добавить сайт на главный экран через меню браузера. PDF-источник и отправка писем требуют интернета.

          Браузер может очистить скачанные файлы при нехватке места или удалении данных сайта. Прогресс можно отдельно сохранить в файл выше.

          После включения офлайн-режима браузер может скачивать новые версии при посещении сайта с интернетом. Чтобы применить готовое обновление, завершите тренировку и закройте все вкладки PilotSpace. При изменении базы сохранение старой тренировки может стать несовместимым.
